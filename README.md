# 💰 Personal Expense Tracker

A clean and simple web-based application to track daily expenses and manage personal finances effectively.

---

## 🚀 Features

- ✅ Add, edit, and delete expenses
- ✅ User authentication (Login & Signup)
- ✅ Dashboard to view expenses
- ✅ Track transactions
- ✅ Simple and user-friendly interface
- ✅ Manage personal financial records

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

---

## 🎯 Why this project?

Managing expenses is an essential real-life problem.

This project helps users:

- Track spending habits
- Stay financially aware
- Improve money management
